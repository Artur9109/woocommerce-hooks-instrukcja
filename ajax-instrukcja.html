1. Wstęp do AJAX

AJAX (Asynchronous JavaScript and XML) to technika programistyczna, która pozwala na wysyłanie danych do serwera i pobieranie ich bez przeładowywania całej strony. Jest to kluczowa technologia dla budowania nowoczesnych, responsywnych aplikacji internetowych.

W tym przewodniku nauczysz się jak używać AJAX do komunikacji asynchronicznej między klientem a serwerem, co jest niezbędne w kontekście WordPress i WooCommerce.

2. Czym jest AJAX?

Definicja i Znaczenie

AJAX to kombinacja kilku technologii:

  • JavaScript - obsługa logiki po stronie klienta
  • XMLHttpRequest lub Fetch API - wysyłanie żądań HTTP
  • JSON/XML - format wymiany danych
  • HTML/CSS - dynamiczna aktualizacja interfejsu

Korzyści AJAX

  • Lepsza responsywność aplikacji
  • Zmniejszenie transferu danych
  • Asynchroniczna komunikacja nie blokuje interfejsu
  • Możliwość aktualizacji części strony bez przeładowania
  • Lepsze doświadczenie użytkownika (UX)

Kiedy Używać AJAX

  • Walidacja formularzy w czasie rzeczywistym
  • Pobieranie danych bez przeładowania strony
  • Autocomplate/sugestie
  • Dynamiczne ładowanie zawartości
  • Operacje asynchroniczne (upload, przetwarzanie)

3. XMLHttpRequest API

Podstawy XMLHttpRequest

XMLHttpRequest (XHR) to starszy, ale ciągle ważny obiekt do wysyłania żądań HTTP. Choć Fetch API jest nowsze, XMLHttpRequest jest nadal wspierane i używane.

Podstawowy Przykład GET

// Utworzenie obiektu XMLHttpRequest
const xhr = new XMLHttpRequest();

// Zdefiniowanie co się stanie gdy odpowiedź będzie gotowa
xhr.onload = function() {
    if (xhr.status === 200) {
        console.log('Sukces:', xhr.responseText);
    } else {
        console.error('Błąd:', xhr.status);
    }
};

// Obsługa błędów
xhr.onerror = function() {
    console.error('Błąd żądania');
};

// Otwarcie żądania (metoda, URL)
xhr.open('GET', 'https://api.example.com/data', true);

// Wysłanie żądania
xhr.send();

POST Żądanie z Danymi

const xhr = new XMLHttpRequest();

xhr.onload = function() {
    const response = JSON.parse(xhr.responseText);
    console.log('Odpowiedź:', response);
};

xhr.open('POST', 'https://api.example.com/submit', true);

// Ustawienie nagłówka Content-Type
xhr.setRequestHeader('Content-Type', 'application/json');

// Wysłanie danych JSON
const data = {
    name: 'John',
    email: 'john@example.com'
};

xhr.send(JSON.stringify(data));

Ustawianie Nagłówków

const xhr = new XMLHttpRequest();

xhr.open('POST', 'https://api.example.com/data', true);

// Ustawianie niestandardowych nagłówków
xhr.setRequestHeader('Content-Type', 'application/json');
xhr.setRequestHeader('Authorization', 'Bearer token123');
xhr.setRequestHeader('X-Custom-Header', 'value');

xhr.send(JSON.stringify({data: 'example'}));
💡 Wskazówka

Nagłówki muszą być ustawione PRZED wywołaniem metody send().

4. Fetch API

Wprowadzenie do Fetch API

Fetch API to nowoczesne API do wysyłania żądań HTTP. Jest to zamiennik dla XMLHttpRequest z czystszą składnią i obsługą Promise.

Podstawowy GET

fetch('https://api.example.com/data')
    .then(response => {
        if (!response.ok) {
            throw new Error(`HTTP error! status: ${response.status}`);
        }
        return response.json();
    })
    .then(data => {
        console.log('Dane:', data);
    })
    .catch(error => {
        console.error('Błąd:', error);
    });

POST Żądanie

const userData = {
    name: 'John Doe',
    email: 'john@example.com'
};

fetch('https://api.example.com/users', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify(userData)
})
    .then(response => response.json())
    .then(data => {
        console.log('Sukces:', data);
    })
    .catch(error => {
        console.error('Błąd:', error);
    });

Fetch z Async/Await

async function fetchData() {
    try {
        const response = await fetch('https://api.example.com/data');
        
        if (!response.ok) {
            throw new Error(`HTTP error! status: ${response.status}`);
        }
        
        const data = await response.json();
        console.log('Dane:', data);
    } catch (error) {
        console.error('Błąd:', error);
    }
}

// Wywołanie funkcji
fetchData();

Zaawansowane Opcje Fetch

const options = {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'Authorization': 'Bearer token123'
    },
    body: JSON.stringify({
        name: 'John',
        email: 'john@example.com'
    }),
    mode: 'cors',
    credentials: 'include',
    cache: 'no-cache'
};

fetch('https://api.example.com/data', options)
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error(error));
✓ Rekomendacja

Fetch API jest zalecaną metodą. Jest nowsza, czystsza i łatwniejsza w użyciu niż XMLHttpRequest.

5. Praktyczne Przykłady

Przykład 1: Walidacja E-maila w Czasie Rzeczywistym

HTML
<input type="email" id="email" placeholder="Wpisz e-mail">
<div id="emailStatus"></div>
JavaScript
document.getElementById('email').addEventListener('blur', async (e) => {
    const email = e.target.value;
    const statusDiv = document.getElementById('emailStatus');
    
    if (!email) {
        statusDiv.innerHTML = '';
        return;
    }
    
    try {
        const response = await fetch('/wp-admin/admin-ajax.php', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/x-www-form-urlencoded'
            },
            body: 'action=validate_email&email=' + encodeURIComponent(email)
        });
        
        const data = await response.json();
        
        if (data.valid) {
            statusDiv.innerHTML = '✓ E-mail jest dostępny';
            statusDiv.style.color = 'green';
        } else {
            statusDiv.innerHTML = '✗ E-mail jest już zarejestrowany';
            statusDiv.style.color = 'red';
        }
    } catch (error) {
        console.error('Błąd:', error);
    }
});

Przykład 2: Dynamiczne Ładowanie Produktów

HTML
<button id="loadMore">Załaduj więcej produktów</button>
<div id="productsList"></div>
JavaScript
let currentPage = 1;

document.getElementById('loadMore').addEventListener('click', async () => {
    try {
        const response = await fetch('/wp-admin/admin-ajax.php', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/x-www-form-urlencoded'
            },
            body: 'action=load_products&page=' + currentPage
        });
        
        const data = await response.json();
        
        if (data.success) {
            const productsList = document.getElementById('productsList');
            data.products.forEach(product => {
                const productDiv = document.createElement('div');
                productDiv.innerHTML = `
                    <h4>${product.name}</h4>
                    <p>Cena: ${product.price} zł</p>
                `;
                productsList.appendChild(productDiv);
            });
            currentPage++;
        }
    } catch (error) {
        console.error('Błąd przy ładowaniu produktów:', error);
    }
});

Przykład 3: Dodawanie do Koszyka bez Przeładowania

document.querySelectorAll('.add-to-cart').forEach(button => {
    button.addEventListener('click', async (e) => {
        e.preventDefault();
        
        const productId = button.dataset.productId;
        const quantity = document.getElementById('quantity').value;
        
        try {
            const response = await fetch('/wp-admin/admin-ajax.php', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/x-www-form-urlencoded'
                },
                body: 'action=add_to_cart&product_id=' + productId + 
                      '&quantity=' + quantity
            });
            
            const data = await response.json();
            
            if (data.success) {
                alert('Produkt dodany do koszyka!');
                updateCartCount(data.cart_count);
            }
        } catch (error) {
            console.error('Błąd:', error);
        }
    });
});

function updateCartCount(count) {
    document.getElementById('cart-count').textContent = count;
}

6. Best Practices

1. Obsługa Błędów

Zawsze obsługuj błędy i błędy sieci:

async function fetchWithErrorHandling(url) {
    try {
        const response = await fetch(url);
        
        if (!response.ok) {
            throw new Error(`HTTP ${response.status}`);
        }
        
        return await response.json();
    } catch (error) {
        console.error('Błąd podczas pobierania:', error);
        // Wyświetl użytkownikowi wiadomość o błędzie
        alert('Coś poszło nie tak. Spróbuj ponownie.');
        throw error;
    }
}

2. Timeouty

Dodaj timeouty do żądań aby uniknąć zawieszenia:

function fetchWithTimeout(url, timeout = 5000) {
    const controller = new AbortController();
    const timeoutId = setTimeout(() => controller.abort(), timeout);
    
    return fetch(url, { signal: controller.signal })
        .then(response => {
            clearTimeout(timeoutId);
            return response.json();
        })
        .catch(error => {
            clearTimeout(timeoutId);
            if (error.name === 'AbortError') {
                throw new Error('Żądanie przekroczyło limit czasu');
            }
            throw error;
        });
}

3. Wskaźnik Ładowania

Pokaż użytkownikowi, że coś się ładuje:

async function loadWithIndicator(url) {
    const loader = document.getElementById('loader');
    loader.style.display = 'block';
    
    try {
        const data = await fetch(url).then(r => r.json());
        return data;
    } finally {
        loader.style.display = 'none';
    }
}

4. Zapobieganie Duplikatom Żądań

class RequestManager {
    constructor() {
        this.pendingRequests = new Map();
    }
    
    async fetch(key, url, options) {
        if (this.pendingRequests.has(key)) {
            return this.pendingRequests.get(key);
        }
        
        const promise = fetch(url, options)
            .then(r => r.json())
            .finally(() => this.pendingRequests.delete(key));
        
        this.pendingRequests.set(key, promise);
        return promise;
    }
}

5. Bezpieczeństwo

  • Zawsze używaj HTTPS dla żądań AJAX
  • Waliduj dane zarówno na kliencie jak i serwerze
  • Używaj nonce'ów w WordPress dla CSRF ochrony
  • Nie przesyłaj wrażliwych danych w URL-u (GET)
  • Nie polegaj na walidacji tylko po stronie klienta
⚠️ Ważne

Zawsze waliduj i sanityzuj dane na serwerze. Walidacja po stronie klienta jest tylko dla wygody użytkownika.

7. Integracja z WordPress/WooCommerce

WordPress AJAX Hook

WordPress dostarcza admin-ajax.php do obsługi żądań AJAX.

Rejestracja AJAX Action

// W pliku functions.php lub pluginu
add_action('wp_ajax_my_action', 'handle_my_ajax_request');
add_action('wp_ajax_nopriv_my_action', 'handle_my_ajax_request');

function handle_my_ajax_request() {
    // Sprawdzenie nonce'a
    if (!isset($_POST['nonce']) || 
        !wp_verify_nonce($_POST['nonce'], 'my_ajax_nonce')) {
        wp_send_json_error('Nonce verification failed');
    }
    
    // Przetwarzanie danych
    $data = sanitize_text_field($_POST['data']);
    
    // Zwrot wyniku
    wp_send_json_success([
        'message' => 'Operacja zakończona pomyślnie',
        'data' => $data
    ]);
    
    die();
}

Obsługa po Stronie Klienta

// Wysłanie żądania AJAX z nonce'em
fetch(ajax_object.ajax_url, {
    method: 'POST',
    headers: {
        'Content-Type': 'application/x-www-form-urlencoded'
    },
    body: 'action=my_action&nonce=' + ajax_object.nonce + 
          '&data=' + encodeURIComponent('example')
})
    .then(response => response.json())
    .then(data => {
        if (data.success) {
            console.log('Sukces:', data.data);
        } else {
            console.error('Błąd:', data.data);
        }
    });

Lokalizowanie Zmiennych

// W PHP (functions.php)
wp_enqueue_script('my-script', get_template_directory_uri() . '/js/my-script.js');

wp_localize_script('my-script', 'ajax_object', [
    'ajax_url' => admin_url('admin-ajax.php'),
    'nonce' => wp_create_nonce('my_ajax_nonce'),
    'site_url' => site_url()
]);

// Dodaj do functions.php
add_action('wp_ajax_custom_woo_action', 'handle_custom_woo_ajax');

function handle_custom_woo_ajax() {
    check_ajax_referer('woo_nonce', 'security');
    
    $product_id = intval($_POST['product_id']);
    
    if (wc_get_product($product_id)) {
        wp_send_json_success([
            'product_id' => $product_id,
            'message' => 'Produkt znaleziony'
        ]);
    } else {
        wp_send_json_error('Produkt nie istnieje');
    }
    
    die();
}

8. Debugging i Rozwiązywanie Problemów

Narzędzia do Debugowania

  • Browser DevTools - Network tab do analizy żądań
  • Console - dla logowania błędów
  • Network Monitor - dla statusów HTTP
  • Storage/Cookies - dla sprawdzenia ciasteczek

Logowanie Debugujące

async function debugFetch(url, options = {}) {
    console.log('🚀 Wysyłam żądanie:', url, options);
    console.time('fetch-' + url);
    
    try {
        const response = await fetch(url, options);
        console.log('📨 Status odpowiedzi:', response.status);
        
        const data = await response.json();
        console.log('✅ Dane odpowiedzi:', data);
        
        return data;
    } catch (error) {
        console.error('❌ Błąd żądania:', error);
        throw error;
    } finally {
        console.timeEnd('fetch-' + url);
    }
}

Częste Problemy

Problem: CORS Error

Objawy: "Access to XMLHttpRequest has been blocked by CORS policy"

Rozwiązanie: Serwer musi wysyłać odpowiednie nagłówki CORS lub używaj względnych URL-i.

Problem: Żądanie nie dociera

Objawy: Brak logów, żadnych błędów

Rozwiązanie: Sprawdź Network tab w DevTools, czy żądanie jest wysyłane.

Problem: Błąd 500 od serwera

Objawy: HTTP 500 error

Rozwiązanie: Sprawdź logi serwera, możliwe błędy PHP.

Problem: Timeout żądania

Objawy: Żądanie trwa zbyt długo

Rozwiązanie: Zwiększ timeout lub sprawdź obciążenie serwera.

Checklist Debugowania

  • ☐ Sprawdź Network tab - czy żądanie jest wysyłane?
  • ☐ Sprawdź status HTTP - 200, 404, 500?
  • ☐ Sprawdź format odpowiedzi - JSON, HTML, XML?
  • ☐ Sprawdź nagłówki - Content-Type, CORS headers
  • ☐ Sprawdź payload - czy dane są wysyłane poprawnie?
  • ☐ Sprawdź konsole - czy są błędy JavaScript?
  • ☐ Sprawdź logi serwera - PHP errors/warnings
  • ☐ Sprawdź nonce - czy jest walidowany poprawnie?
